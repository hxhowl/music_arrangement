## 第三轮：审核「描述 → 全新编曲」可行性（commit a73743c）

产出 `docs/description-to-arrangement-audit.md`。

结论：**能做「新的一版」，做不了「新的编曲」**。描述只能改 bpm / sections / velocity，
调性、和弦进行、律动、织体、旋律性格全部写死。

实测证据：a-sad（60bpm/Am/3段）与 b-fast（150bpm/C/3段）产出的和弦音
（50/52/54 = D3/E3/F#3）与贝斯线（33/38/40/42）**完全一致**。

四个断点：
1. 和弦进行仍在全局 `theory.py: PROGRESSION`，四个 pattern 直接 import
   → 换歌必改全局，违反创作隔离。这是上一轮「全局 config」的同款病，藏得更深。
2. 只有一套织体，config 里没有 `style` 字段，代码里也没有第二套律动可选。
3. brief.md 无代码消费；四个项目级 skill 实测 `Can not find skill`，未注册。
4. 没有 new_song 脚手架，靠手写 config.json，易漏配。

改造方案：①级数化和弦 + key 推导 ②style 维度 + cinematic/pop/lofi 三套律动
③tools/new_song.py。待用户确认后动手。
