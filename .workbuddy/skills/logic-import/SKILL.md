# logic-import

## 导入方式
- 拖 .mid 到 Tracks 区，或 File > Import > MIDI File
- 完整编曲用 File > Open 开新工程

## 音色映射建议
- lead → Alchemy / ES2
- chords → Pad / Alchemy
- bass → Studio Bass / 合成贝斯
- drums → Drum Machine Designer（GM 预设对照）
- pad → Sculpture / Strings

## 检查表
- 鼓是否落在正确键位
- BPM/调性是否对齐
- 副歌动态是否起来
- 留白是否够

## 输出
bounce 30s preview 回传 WorkBuddy 做 mix-review（后续扩展）
