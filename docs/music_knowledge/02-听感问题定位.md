# 听感问题定位：听到"不对劲"，该动哪一层

这份文档解决一个具体问题：**听完一版说不出哪里不对，或者知道不对但不知道改什么。**

前提是先读 [01-分轨策略.md](01-分轨策略.md) —— 这里所有的"层"都是那 8 个功能位。

---

## 一、调的顺序：从骨架往上

不要一上来就调旋律。顺序错了会反复返工，因为上层的问题往往是下层引起的。

### 第 1 步：骨架（`drums` + `bass`）

在 Logic 里把其他轨全静音，只听这两条。

- 拍点稳吗？能跟着点头吗？
- 这两条决定"这是什么风格"：cinematic 是心跳、pop 是标准 4/4、lofi 是半拍、playful 是错位重音。
- 这一层不对，上面加什么都是错的。

### 第 2 步：和声（`chords`）

加进 `chords`。

- 能听出和弦在变吗？（`harmonic_rhythm` 控制变得多快）
- 和弦换的时候有没有"整块跳"的感觉？如果有，是本该平滑的声部进行被破坏了。
- 和声听着"硬"或"块状"，通常是和弦排列太挤在一个八度里。

### 第 3 步：旋律（`lead`）

加进 `lead`。

- 旋律清楚吗？**这是全流程最容易出问题的一步**，因为其他层会抢它。
- 判断标准：闭眼听，能不能哼出那条线。哼不出 = 被掩蔽了。

### 第 4 步：填缝（`pad` / `arp` / `perc` / `counter`）

逐个加，每加一个问一句：**它解决了什么问题？** 答不上来就关掉。

顺序建议：`pad` → `perc` → `arp` → `counter`。
`counter` 放最后，因为它是机会性声部，取决于主旋律留了多少空。

## 二、症状对照表

| 症状 | 怎么听出来 | 多半是哪一层 | 先动这个 |
|---|---|---|---|
| **整体糊** | 所有声音抱成一团，分不清谁是谁 | 低频（bass 与底鼓抢）+ 中频（pad 与 chords 抢） | `style_tweaks.pad.duck` 压更多；`style_tweaks.bass.velocity` 降；`arrange.<段>.drums` 降一档 |
| **旋律听不清** | 知道有旋律，但抓不住 | `lead` 被同音叠置或音区太近 | 先跑 `bash tools/check.sh` 看"同音高同时发声"；再降 `style_tweaks.pad.velocity`、把 `style_tweaks.arp.range` 下移 |
| **空** | 有骨架、有和声，但没内容 | 缺 `pad` 或 `arp` | `arrange.<段>.arp` 开成 `true`；`style_tweaks.pad.hold` 加大让长音连起来 |
| **平 / 没起伏** | 从头到尾一个样，听完记不住 | 段落之间没有动态差 | `arrange.<段>.build: "up"`（段内渐强，副歌默认开）；`arrange.<段>.vel` 拉开差距（0.65 / 0.85 / 1.0）；`arrange.chorus.style` 换风格；`arrange.<段>.drums` 分档 |
| **吵 / 听两分钟就累** | 耳朵疲劳，想调小音量 | `perc` / `arp` 太密，或鼓一直满编 | `style_tweaks.perc.step` 从 0.5 改成 1.0（少一半）；`style_tweaks.fill_every` 加大；副歌 `drums` 降到 `medium` |
| **低频浑 / 像一团** | 底鼓和贝斯分不开 | `bass` 与底鼓同拍、同音区 | 先把 `style_tweaks.bass.velocity` 降一点试；不够就改 `style_tweaks.bass.rhythm` 把重音错开底鼓的位置 |
| **太"方" / 像节拍器** | 节奏太齐，没有"人味" | 没有 swing、没有切分 | `swing: 0.33`；或 `style_tweaks.bass.rhythm` 加一个反拍 |
| **副歌没"起来"** | 副歌和主歌差不多响、差不多密 | 层数 / 密度 / 力度没差 | `arrange.chorus.build` 用默认的 `"up"`（前半 medium、后半 full）；`arrange.chorus.vel` 到 1.0；确认 `lead` 只在副歌开、`counter` 在主歌开 |
| **副歌想再加一层，但加什么都抢旋律** | 副歌已经满，再塞声部就糊 | 缺一条**上方**的线 | `arrange.chorus.counter: true` + `arrange.chorus.counter_voice: "high"`；配中提琴 / 圆号 / 长笛（别配大提琴） |
| **结尾突然断** | 最后一小节硬切掉 | 没有收尾 | `sections` 里加长 `outro`；`cues` 补一个 downlifter 点位 |
| **和声听着"错"** | 某个和弦上旋律很别扭 | 旋律没落在和弦音上 | 这个不该发生（`lead` 按和弦音级取音）。如果发生，说明 `progression` 与 `key` 不匹配，检查一下是不是大小调混用了 |

> 表里的 `style_tweaks` 对**整首**生效；`arrange.<段>` 只对那一段生效。
> 想只改副歌，就用 `arrange`；想改整首歌的同一个参数，用 `style_tweaks`。

## 三、在 Logic 里怎么听

1. **静音法**：按上一节的顺序逐层加，不要一上来就听全轨。听全轨只能得到"不对劲"这种结论。
2. **参考曲**：找一首你想要的听感放在旁边，A/B 对比。人对"绝对好坏"的判断很不稳，
   对"比它亮还是比它暗"却很准。
3. **小段落循环**：`File > Bounce > Section` 或者直接划 cycle 区听 8 小节。
   整首来回拉会漏掉细节。
4. **先听后调**：每次只改一个参数，听完再改下一个。同时改三样，最后不知道是哪样起的作用
   —— 这条纪律在 `skills/midi-iterate/SKILL.md` 里也是硬要求。

## 四、三个常见误解

**误解 1：轨越多越丰富。**
不是。功能重复的轨只会互相掩蔽。8 条轨里如果 `arp` 和 `chords` 弹的是同一批音，
听起来不是"更满"，是"更糊"。加轨之前先问：它干的是哪一层没被覆盖的活？

**误解 2：音色和音区重叠就是问题。**
不是。真实乐器音域本来就大面积重叠（钢琴几乎覆盖所有乐器）。
真正的问题是**同一时刻响同一个音高** —— 同频叠置会互相抵消，旋律丢掉轮廓。
体检只查这一项，不查音区重叠，就是这个原因。

**误解 3：力度越大越有冲击力。**
不是。冲击力来自**对比**，不是绝对值。所有轨都拉到 100，结果是"一直很响"，
反而没有高潮。副歌之所以"起来"，是因为主歌留了余地。
