# MIDI 到 Logic：乐器到底怎么"对"

这篇解释一个几乎每个用这套工程的人都会撞上的问题：
**生成出来的 MIDI 拖进 Logic，音色怎么不是我以为的那个。**

结论先放这儿：不是生成错了，是 **MIDI 里根本没有"乐器"这个信息**，
只有一串数字；你听到的音色，是"数字 → 谁去解释这串数字"的结果。

---

## 一、一份 MIDI 里到底有什么

一条 MIDI 音符只带四样东西：音高、起始时间、时长、力度。
此外每条轨上还有一个 **program change**（0~127），意思是"我建议用第 N 号音色"。

它**没有**、也**不可能有**的信息：

- 音色叫什么名字（表格是软件查的）
- 用哪个采样库（Logic 自带的？Kontakt？）
- 该加什么效果器

所以"乐器对应"从来不是文件属性，而是**接收方怎么解释这个号**。

---

## 二、谁在解释这个号：两套完全不同的音色库

| | 是什么 | 什么时候生效 |
|---|---|---|
| **GM 音色库** | 操作系统自带的 128 个"能发对音高"的兜底音色（macOS 里是 `gs_instruments.dls`） | Logic 打开 `.mid` 时默认用它 |
| **Logic 音色库** | 几千个带采样、带效果链的 patch（Library 面板里那些） | 你手动选了才用 |

事实是：**Logic 导入 MIDI 时只用第一套**。它按 program 号加载 GM 音色，轨道名也取 GM 名。
所以你看到 `Strings`、`Piano 1`，而不是我们工程里写的 `chords=弦乐群`。

GM 音色的定位是"不会错得太离谱"，不是"好听"。拿它跟 Logic 的弦乐群比，
就像拿电子琴的 8 号音色比真的弦乐四重奏。

> 顺带解释一个常见困惑：为什么 GM 表里 0 号叫 `Piano 1`，我们的弦乐器里 48 号叫 `Strings`，
> 而 Logic 里又有叫 `Studio Grand` 的东西 —— 因为它们根本不是同一张表。
> 本机这两张表的真实内容在 `references/gm-programs.md` 与 `references/logic-patches.md`。

---

## 三、通道 10 是唯一的例外

鼓和打击乐固定落在 MIDI 通道 10（0 基是 9）。在这条通道上，
**program 号选的是"鼓组"，不是音色**：

| 号 | 鼓组 |
|---:|---|
| 0 | Standard |
| 8 | Room |
| 16 | Power |
| 24 | Electronic |
| 40 | Brush |

同一个 0 号，在钢琴轨上是 `Piano 1`，在通道 10 上是 `Standard` 鼓组 —— 这就是"一码两用"。

还有一个坑：**Logic 的 Drum Machine Designer 不读 program 号**，它在工程里记自己那套 kit。
所以用 DMD 的时候，鼓组永远不会跟着 MIDI 变，必须手动选。

## 四、那"换乐器"到底换了什么

这里要跟 [03-乐器选择.md](03-乐器选择.md) 里那条线接上：

- **program 号**只影响"提示别人加载什么"；
- **演奏法微调**（`tweaks`）才会真的改音符 —— 弦乐把长音拉满、吉他把和弦缩短；
- **你在 Logic 里加载什么**决定最终音色。

三者里只有第二个被写进了 MIDI 的音符本身，另外两个都是"建议"。
所以换完乐器觉得"还是不像"，问题通常在演奏法，不在音色（判断标准见 03 末节）。

## 五、实操：四步，做一次就够

1. **导入**：把 `<name>-vN.mid` 拖进空白工程；
2. **改名**：按 `chords / bass / drums / perc / arp / lead / counter / pad` 重命名轨道，
   和工程里的槽名对齐；
3. **换音色**：逐轨在 Library 里换（每个槽搜什么词，见 `references/logic-import.md`）；
4. **存模板**：`文件 > 存储为模板`。以后每首导入后套这套 channel strip，就不用再对一遍。

第 4 步是这件事唯一的"一劳永逸"。不做的话，每首歌都要重来十分钟。

---

## 六、怎么判断"对上了"

不用听音色像不像，用三个可验证的标准：

| 检查 | 对上了的表现 |
|---|---|
| 轨道数 | 和工程里的 8 个槽一致（空轨不会写进文件，所以可能少于 8） |
| 轨道名 | 你改完之后，名字就是槽名，不再出现 `Piano 1` 这种 |
| 鼓组 | 只有 `drums` / `perc` 落在通道 10；其余轨不该出现打击乐音色 |

再补一条经验：**如果某条轨听着"音高对但音色很塑料"，那是 GM 音色，说明你还没换。**
GM 音色的特征是"干、薄、没有房间感"。

---

## 七、想让它自动对上，为什么做不到

MIDI 只有 program / bank / channel 三个数字可以指路，而这三者指的是 GM/GS/XG 的库编号，
不是 Logic 的 patch 名。所以"文件里写一句'请加载 Studio Grand'"这件事，格式上就不存在。

替代方案只有两个，而且都得做一次：

1. **一次手动对 + 清单**（本文 + `references/logic-import.md`）；
2. **模板工程**（对完之后复用）。

如果哪天 Logic 支持了"导入时按 patch 名匹配"，这套东西就能自动化 —— 但目前没有。
