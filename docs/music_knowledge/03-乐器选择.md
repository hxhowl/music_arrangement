# 乐器选择：8 个功能槽用什么声音

前提：功能槽决定**干什么活**（见 [01-分轨策略.md](01-分轨策略.md)），乐器决定**用什么声音干**。
两件事分开之后，换乐器不用动结构，换结构也不用动音色。

---

## 一、选乐器实际在选三样东西

这一点必须先说清楚，否则会误以为"选了吉他就会听起来像吉他"。

| 层 | 代码能做什么 | 效果 |
|---|---|---|
| **GM program 号** | 写进 MIDI 文件（0~127） | 导入 Logic 时给它一个"该加载什么音源"的提示 |
| **演奏法微调** | 真的改音符（长音拉满、和弦变短、换打击乐） | 听感真的会变 |
| **你在 Logic 里加载什么** | 管不到 | 最终音色由这里决定 |

所以"换成吉他"的完整含义是：program 变成 24/25、和弦时值缩短、**并且你会在 Logic 里加载一个吉他音源**。
少了第三步，前两步只是让 MIDI 看起来更像吉他。

还有一个前提：**program 只是提示**。Logic 用 `File > Open` 打开 MIDI 时会按 GM 分配软件乐器；
如果它没照做（或者你想用第三方音源），手动加载即可，MIDI 本身不受影响。

## 二、每个槽的推荐

`*` 是出厂默认（和老版本产物一致）。想换就在 `config.json` 里写 `instruments`。

### chords（和声层）

| 乐器 | 什么时候用 |
|---|---|
| `piano` *原声钢琴 | 通用，柱式和弦最贴它的性格 |
| `epiano` 电钢琴 | lofi / 流行，柔和不抢人声 |
| `strings` 弦乐群 | 电影感首选，会自动把和弦拉长到接近整小节 |
| `nylon` 尼龙弦吉他 | ⚠️ 民谣 / 亲子。柱式和弦对吉他略假，需要扫弦才像 |
| `steel` 钢弦吉他 | ⚠️ 流行扫弦。缺扫弦时序，建议只当铺底 |
| `organ` 拉杆风琴 | 复古 / 福音，铺满不换气 |

### bass（低音）

| 乐器 | 什么时候用 |
|---|---|
| `finger` *指弹电贝斯 | 通用，最不容易出错 |
| `pick` 拨片电贝斯 | 摇滚 / 流行，更硬更亮 |
| `upright` 立式贝斯 | jazz / lofi / 民谣，木头味 |
| `synth` 合成贝斯 | 电子 / 短视频，低频更整齐 |

### drums（鼓组）

GM 鼓组靠 program 号在 channel 10 上区分：`standard` 标准 / `room` 更自然 / `power` 更重 /
`electronic` 电子 / `brush` 刷子（柔软，lofi 好用）。perc 轨会跟随这里选的鼓组。

> 注意：Logic 的 Drum Machine Designer 不吃这个 program 号，它会用自己当前的 kit。
> 这个字段的意义是"告诉你该选哪套鼓"，不是"自动换鼓"。想真换，在 DMD 里选。

### perc（装饰打击）

`shaker` *沙锤 / `tambourine` 铃鼓 / `rim` 鼓边侧击 / `congas` 康加 / `clap` 拍手。
选它会**真的换掉音符**（`perc.gm`），不只是提示。

> perc 和 drums 共用 channel 10，而一个通道同一时刻只能有一套鼓组。
> 所以 perc **没有自己的 program 号**，它的鼓组永远跟着 `drums` ——
> 否则后写的那条轨会把前一条的鼓组覆盖掉（这条以前真的踩过：
> cinematic 选了 Room 鼓组，导进 Logic 却是标准鼓组）。

### arp（琶音）

| 乐器 | 什么时候用 |
|---|---|
| `synth` *合成琶音 | 电子 / 流行，中高频亮 |
| `pluck` 拨弦 | 比合成器像真乐器，会把步长放到 8 分 |
| `harp` 竖琴 | 亲子 / 童话，颗粒清楚 |
| `marimba` 马林巴 | 温暖木质，lofi 好用 |
| `glocken` 音铃 | 点缀，少用，容易刺耳 |

### lead（主旋律）

| 乐器 | 什么时候用 |
|---|---|
| `synth_lead` *方波主音 | 通用，中性 |
| `flute` 长笛 | 亲子 / 民谣，柔、不刺；会自动加呼吸 |
| `violin` 小提琴 | ⚠️ 电影感；需要连弓与揉弦 |
| `sax` 中音萨克斯 | ⚠️ 爵士 / 都市；缺弯音会偏「直」 |
| `harmonica` 口琴 | ⚠️ 公路 / 怀旧；辨识度极高，容易露馅 |
| `whistle` 哨笛 | 亲子 / 田园，亮但不需要力度 |

### counter（副旋律）

`cello` *大提琴 / `viola` 中提琴 / `french_horn` 圆号 / `bassoon` 巴松。
这一槽本来就是"低音区答句"，配大提琴和圆号最自然。

### pad（铺底）

| 乐器 | 什么时候用 |
|---|---|
| `polysynth` *合成铺底 | 中性，什么都不冲突 |
| `warm` 暖 Pad | 比 polysynth 柔，适合 lofi |
| `strings` 弦乐群 | 电影感首选，会自动拉长并压低让位 |
| `choir` 人声合唱 | 圣洁 / 空灵；会占中频，已自动压到 28 |
| `church` 教堂风琴 | 庄严，低频厚，慎用 |

## 三、五个编制预设

预设 = 一次配好 8 个槽。新项目会按风格自动带一个，也可以用 `--preset` 指定。

| 预设 | 编制 | 适合 |
|---|---|---|
| `band` | 电钢琴 / 指弹贝斯 / 标准鼓 / 铃鼓 / 拨弦 / 方波主音 / 大提琴 / 暖 Pad | 流行、短视频 |
| `cinematic` | 弦乐群 / 立式贝斯 / Room 鼓 / 沙锤 / 竖琴 / 小提琴 / 圆号 / 弦乐群 | 电影感、叙事 |
| `lofi` | 电钢琴 / 立式贝斯 / 刷子鼓 / 沙锤 / 马林巴 / 长笛 / 大提琴 / 暖 Pad | 慵懒、背景 |
| `acoustic` | 尼龙弦吉他 / 立式贝斯 / 刷子鼓 / 康加 / 竖琴 / 长笛 / 大提琴 / 弦乐群 | 原声、亲子 |
| `electronic` | 电钢琴 / 合成贝斯 / 电子鼓 / 拍手 / 合成琶音 / 方波主音 / 大提琴 / 合成铺底 | 电子、卡点 |

风格 → 预设的自动对应：`cinematic → cinematic`、`pop → band`、`lofi → lofi`、`playful → band`。

## 四、三种换法，以及优先级

**1. 换整套**（`config.json`）

```jsonc
"preset": "lofi"
```

**2. 换一两个槽**（`config.json`）

```jsonc
"preset": "cinematic",
"instruments": { "chords": "piano", "lead": "flute" }
```

**3. 建项目时一次说清**

```bash
bash tools/new_song.sh "60秒 亲子 温柔" --preset acoustic --instruments "lead=whistle"
```

**看有哪些可选：**

```bash
bash tools/instruments.sh                    # 全部槽位与选项
bash tools/instruments.sh --preset lofi      # 只看某个预设
bash tools/instruments.sh --project projects/demo   # 看这首歌当前用什么
```

优先级（后者覆盖前者）：

```
出厂默认  <  编制预设 preset  <  config.instruments  <  config.style_tweaks
```

`style_tweaks` 最高，因为它是"我明确要改这个参数"。
换句话说：选了弦乐群但想把长音改短，写 `style_tweaks.chords.hold` 就压得过它。

## 五、什么时候该换编制，什么时候该改代码

| 你的想法 | 该做什么 |
|---|---|
| "把钢琴换成电钢琴" | 换 `instruments.chords` |
| "整体换成电影感编制" | 换 `preset` |
| "钢琴和吉他同时弹和弦" | 在 Logic 里复制 `chords` 那轨，两轨各换音色（不用改代码） |
| "想要真的扫弦/连弓/弯音" | 这时才值得写新 pattern —— 那是演奏法，不是音色 |

判断标准还是那一句：**换完音色能不能听出区别**。能 → 音色问题，换乐器就够；
不能（或者听着"假"）→ 演奏法问题，换乐器解决不了。

## 六、一个实测

`demo` 从 v7 换到 v8 只做了一件事：`preset: "cinematic"`。

```
v7  chords=钢琴(0)   bass=指弹贝斯(33)  arp=合成(81)  lead=方波(80)  counter=大提琴(42)  pad=合成(90)
v8  chords=弦乐群(48) bass=立式贝斯(32)  arp=竖琴(46)  lead=小提琴(40) counter=圆号(60)    pad=弦乐群(48)
```

**音符层面只有 `pad` 变了**：长音从 1.0 小节缩到 0.99、力度 30→29
（弦乐群自带 `hold=0.99` / `duck=0.70`）。`chords` 也换成了弦乐群，但音符没动 ——
因为 `cinematic` 风格本身就把和弦拉得很长，弦乐群需要的"长音"它已经满足了。
这也是个有用的观察：

> **编制预设主要改音色；演奏法微调只在乐器需要不同弹法时才动音符。**

所以如果你换完编制觉得"还是那个味儿"，问题大概率在**结构**（段落、律动、和声节奏），不在乐器。
